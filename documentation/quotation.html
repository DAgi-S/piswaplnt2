Quotation Management System Documentation

Overview

The Quotation Management System is a comprehensive solution for creating, managing, and sending quotations to clients. It provides functionality for creating, viewing, updating, and deleting quotations, with integrated email capabilities for sending quotations directly to clients.

Database Structure

Tables

1. quotations
Column Type Description
id INT Primary key, auto-increment
quotation_number VARCHAR(50) Unique quotation number (e.g., Q000001)
client_id INT Foreign key to clients table
quotation_date DATE Date of quotation
valid_until DATE Quotation validity date
sub_total DECIMAL(25,2) Total before VAT
vat DECIMAL(25,2) VAT amount (15%)
grand_total DECIMAL(25,2) Total including VAT
status INT Quotation status (1=Active, 2=Accepted, 3=Declined)
2. quotation_items
Column Type Description
id INT Primary key, auto-increment
quotation_id INT Foreign key to quotations table
product_id INT Foreign key to products table
quantity INT Quantity quoted
rate DECIMAL(25,2) Price per unit
total DECIMAL(25,2) Total amount (quantity * rate)

Features

  • Create, read, update, and delete quotations
  • Email quotations to clients
  • VAT calculation (15%)
  • Multiple products per quotation
  • Client management
  • Quotation validity period
  • Status tracking
  • Input validation

Create Quotation

Process Flow

  1. Select client (or create new)
  2. Set quotation date and validity period
  3. Add products with quantities and rates
  4. System calculates totals automatically
  5. Add optional terms and conditions
  6. Save quotation
  7. Option to email quotation immediately

View Quotations

The system displays quotations in a DataTable with the following information:

  • Quotation number
  • Date
  • Client
  • Valid until
  • Sub Total
  • VAT
  • Grand Total
  • Status
  • Actions (Edit/Delete/Email)

Update Quotation

Process Flow

  1. Load existing quotation details
  2. Modify client, dates, products, or quantities
  3. System recalculates totals
  4. Update status if needed
  5. Save changes
  6. Option to resend updated quotation

Delete Quotation

Process Flow

  1. Confirm deletion
  2. Soft delete quotation (mark as inactive)
  3. Remove quotation items
  4. Maintain record for reporting

Email Functionality

Features

  • Send quotations directly to clients
  • Professional email template
  • Includes company details
  • Lists all quotation items
  • Shows totals and VAT
  • Includes terms and conditions

Email Configuration

  • SMTP settings in emailConfig.php
  • Supports Gmail SMTP
  • Requires secure authentication
  • HTML email format

Validation

Required Fields

  • Client
  • Quotation Date
  • Valid Until Date
  • At least one product
  • Product quantity and rate
  • Client email for sending quotations

Business Rules

  • Valid Until date must be after Quotation Date
  • Quantity must be positive
  • Rate must be positive
  • VAT is calculated at 15%
  • Email address must be valid
