Database Structure

guest_users Table

Column Type Description
id int Primary key
username varchar Guest's login username
password varchar Hashed password
guest_id varchar Unique identifier for the guest (e.g., GUEST001)
full_name varchar Guest's full name
account_name varchar Name of the linked account
currency varchar Account currency
balance decimal Account balance
linked_account_id int Foreign key to accounts table
access_level json Array of permissions
status tinyint 1 = Active, 0 = Inactive
created_at datetime Account creation timestamp
last_login datetime Last login timestamp
expiry_date date Account expiration date

accounts Table

Column Type Description
id int Primary key
account_owner varchar Owner of the account
account_platform varchar Platform name (e.g., PayPal)
Currency varchar Account currency
number_of_transactions int Total transactions count
satstus tinyint 1 = Active, 0 = Inactive

Functionality

Fetching Guests

The system uses DataTables to display guest information. The key query in fetchGuests.php:

SELECT 
    g.*,
    a.account_owner,
    a.account_platform,
    a.Currency as account_currency
FROM guest_users g
LEFT JOIN accounts a ON g.linked_account_id = a.id
ORDER BY g.id DESC

DataTable Initialization

The DataTable is initialized in guest.js with these settings:

$('#guestTable').DataTable({
    'ajax': {
        'url': 'php_action/fetchGuests.php',
        'type': 'GET'
    },
    'order': [[0, 'desc']],
    'columnDefs': [
        {
            'targets': [3, 4, 9],
            'orderable': false,
            'searchable': false
        }
    ]
});

Troubleshooting

Common Issues and Solutions:

  1. Data Not Displaying:
    • Check database connection in core.php
    • Verify SQL query matches table structure
    • Check browser console for JavaScript errors
    • Ensure DataTables library is properly loaded
  2. Permission Issues:
    • Verify user has 'manage_guests' permission
    • Check access_level JSON format in database
  3. Account Linking:
    • Ensure accounts table has correct status field (satstus)
    • Verify linked_account_id references valid account

Important Notes

  • Always validate guest_id format (e.g., GUEST001)
  • Ensure proper error handling in all AJAX requests
  • Keep access_level JSON format consistent
  • Regular maintenance of expired guest accounts
