5. Usage Instructions

  1. The orders table is automatically initialized when viewing the manage orders page
  2. Payment status can be updated through the edit form or payment status modal
  3. Table supports sorting, searching, and pagination by default
  4. Actions available for each order:
    • Print - Generate printable invoice
    • Edit - Modify order details
    • Remove - Delete the order

6. Calculations

  • Sub Total: Sum of all line items
  • VAT: 15% of sub total
  • Total Amount: Sub total + VAT
  • Grand Total: Same as Total Amount
Note: All monetary values are automatically formatted to 2 decimal places for consistency.

7. Error Handling

  • DataTable initialization errors are prevented through proper instance management
  • Payment status defaults to "No Payment" if invalid status is received
  • Table automatically handles empty data sets
