Digital Swap Module Documentation

Overview

The Digital Swap module manages digital currency transactions between different accounts and platforms. It supports both deposits and withdrawals, with comprehensive tracking and reporting capabilities.

Database Structure

Tables

1. digital_swaps

Column Type Description
id INT Primary key, auto-increment
transaction_date DATE Date of the transaction
type VARCHAR(50) Transaction type (deposit/withdraw)
account_id INT Foreign key to accounts table
name VARCHAR(255) Name of the transaction
platform VARCHAR(100) Platform used for the transaction
amount DECIMAL(15,2) Transaction amount
comment TEXT Additional notes about the transaction
status TINYINT Transaction status (1: Active, 0: Inactive)
created_at TIMESTAMP Record creation timestamp
updated_at TIMESTAMP Last update timestamp

Features

1. Transaction Management

  • Create new digital swap transactions
  • Edit existing transactions
  • Delete transactions
  • View transaction details

2. Digital Swap Report

The Digital Swap Report provides a comprehensive view of transactions within a specified date range.

Report Features:

  • Date range selection (Start Date and End Date)
  • Account filtering
  • Transaction type filtering (All Types/Deposit/Withdraw)
  • Email report functionality

Report Columns:

  • Transaction Date
  • Type (Deposit/Withdraw)
  • Name
  • Platform
  • Account
  • Amount
  • Comment

Report Totals:

  • Total Deposits
  • Total Withdrawals
  • Net Balance
Important Update (2024):
  • Reports now use transaction_date instead of created_at for date filtering
  • Enhanced report generation with responsive table design
  • Added support for email report delivery
  • Improved date range filtering accuracy

API Endpoints

1. Get Digital Swap Report

Endpoint: php_action/getDigitalSwapReport.php

Method: POST

Parameters:

  • startDate (required): Start date for report period (YYYY-MM-DD)
  • endDate (required): End date for report period (YYYY-MM-DD)
  • type (optional): Transaction type filter (deposit/withdraw)
  • accountId (optional): Specific account ID to filter

Response:

{ "success": true, "html": "HTML content of the report", "styles": "CSS styles for the report" }

2. Send Digital Swap Report

Endpoint: php_action/sendDigitalSwapReport.php

Method: POST

Parameters:

  • startDate (required): Start date for report period
  • endDate (required): End date for report period
  • email (required): Email address to send the report to
  • type (optional): Transaction type filter
  • accountId (optional): Account filter

Response:

{ "success": true, "messages": "Report sent successfully", "debug": [] // Debug information if enabled }
