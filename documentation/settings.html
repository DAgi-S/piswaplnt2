System Settings Documentation

Overview

The System Settings module provides comprehensive management tools for system configuration, user management, and data organization. It includes:

  • User Management - Create and manage system users
  • Roles & Permissions - Control access levels
  • Brand Management - Organize product brands
  • Category Management - Manage product categories
  • Account Settings - Configure system accounts

User Management

Features

  • Create new users
  • Assign user roles
  • Manage user permissions
  • Reset passwords
  • Activate/deactivate users

User Fields

Field Type Description
Username Text Unique user identifier
Email Email User's email address
Password Password Securely hashed password
Role Select User's system role

Roles & Permissions

Available Roles

  • Administrator (Role ID: 2)
  • Standard User
  • Limited User

Permission Types

Permission Description
view_user Access to view user list
create_user Ability to create new users
edit_user Permission to edit users
delete_user Authority to delete users

Brand Management

Features

  • Create new brands
  • Edit brand information
  • Set brand status
  • Delete brands

Brand Fields

Field Type Description

Status Select Available/Not Available

Database Structure

Users Table

Column Type Description
user_id INT Primary key
username VARCHAR(255) User's login name
email VARCHAR(255) User's email
password VARCHAR(255) Hashed password
role_id INT Foreign key to roles

Brands Table

Column Type Description
brand_id INT Primary key
brand_name VARCHAR(255) Brand name
brand_status INT 1=Available, 2=Not Available

Categories Table

Column Type Description
categories_id INT Primary key
categories_name VARCHAR(255) Category name
categories_status INT 1=Available, 2=Not Available
