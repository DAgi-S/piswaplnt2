Accounts Management System Documentation

Overview

The Accounts Management System is a comprehensive solution for managing digital platform accounts. It provides functionality for creating, viewing, updating, and deleting account records, with integrated balance management and account type classification.

Key Features

  • Account creation with type classification
  • Real-time balance tracking
  • Transaction history management
  • Account status management
  • Balance updates and reconciliation
  • Account type modification

Database Structure

Tables Overview

Table Name Description Primary Key Foreign Keys
accounts Stores main account information including balance and type account_id user_id (users)
account_types Defines different types of accounts available in the system type_id None
account_transactions Records all transactions affecting account balances transaction_id account_id (accounts)

accounts Table Structure

Column Name Data Type Description Constraints
account_id INT Unique identifier for the account PRIMARY KEY, AUTO_INCREMENT
account_name VARCHAR(255) Name of the account NOT NULL
account_type INT Type of account (references account_types) NOT NULL, FOREIGN KEY
current_balance DECIMAL(10,2) Current balance of the account NOT NULL, DEFAULT 0.00
status TINYINT Account status (1: Active, 0: Inactive) NOT NULL, DEFAULT 1
created_at TIMESTAMP Account creation timestamp NOT NULL, DEFAULT CURRENT_TIMESTAMP
updated_at TIMESTAMP Last update timestamp ON UPDATE CURRENT_TIMESTAMP

Relationships

  • accounts.account_type → account_types.type_id (Many-to-One)
  • account_transactions.account_id → accounts.account_id (Many-to-One)

Create Account

Process Flow

  1. Access the Create Account form
  2. Enter account details (name, type, initial balance)
  3. Submit form for validation
  4. System creates account record
  5. Confirmation message displayed

Required Fields

  • Account Name
  • Account Type
  • Initial Balance

View Accounts

Display Features

  • List view of all accounts
  • Sortable columns
  • Search functionality
  • Filter by account type
  • Export capabilities

Update Account

Editable Fields

  • Account Name
  • Account Type
  • Current Balance
  • Status

Process Flow

  1. Select account to edit
  2. Modify required fields
  3. Submit changes
  4. System updates record
  5. Confirmation message displayed

Delete Account

Process Flow

  1. Select account to delete
  2. Confirm deletion
  3. System marks account as inactive
  4. Confirmation message displayed

Important Notes

  • Soft deletion implemented (status update)
  • Associated records preserved
  • Reactivation possible through admin panel

Balance Management

Features

Transaction Types

Input Validation

API Reference

Account Management Endpoints

Endpoint Method Description Parameters
/php_action/createAccount.php POST Create a new account account_name, account_type, initial_balance
/php_action/fetchAccounts.php GET Retrieve all accounts None
/php_action/fetchSelectedAccount.php GET Retrieve specific account details account_id
/php_action/updateAccount.php POST Update account details account_id, account_name, account_type, current_balance
/php_action/removeAccount.php POST Delete/deactivate account account_id

Response Format

{
    "success": true/false,
    "messages": "Operation successful/error message",
    "data": {
        // Response data object
    }
}

Error Handling

  • 400 Bad Request - Invalid input parameters
  • 401 Unauthorized - Authentication required
  • 403 Forbidden - Insufficient permissions
  • 404 Not Found - Account not found
  • 500 Internal Server Error - Server-side error
