Reports System Documentation

Audit Report

The Audit Report provides a detailed monthly view of transactions across multiple accounts, allowing for comprehensive financial tracking and auditing.

Features

  • Multiple account selection (USD and ETB accounts)
  • Year selection for filtering data
  • Monthly breakdown of transactions
  • Separate sections for USD and ETB transactions
  • Monthly totals for deposits and withdrawals
  • Running balance calculations
  • Print-friendly layout

Using the Audit Report

  1. Navigate to Accounts > Audit Report
  2. Select the desired accounts:
    • Choose USD accounts
    • Choose ETB accounts
  3. Select the year for the report
  4. Click "Generate Report" to view the data

Report Sections

  • Monthly Transaction Details:
    • Date and time of transaction
    • Transaction type (Deposit/Withdrawal)
    • Amount
    • Running balance
    • Comments/Notes
  • Monthly Summaries:
    • Total deposits
    • Total withdrawals
    • Net change
    • Closing balance

Annual Report

The Annual Report provides a year-over-year comparison of financial activities, helping track long-term financial trends and performance.

Features

  • Multiple account selection
  • Year range selection
  • Yearly summaries
  • Currency-wise breakdowns
  • Comparative analysis
  • Print-optimized layout

Using the Annual Report

  1. Navigate to Accounts > Annual Report
  2. Select accounts to include:
    • USD accounts
    • ETB accounts
  3. Choose the year range:
    • From Year
    • To Year
  4. Click "Generate Report" to view the data

Report Sections

  • Yearly Summaries:
    • Total annual deposits
    • Total annual withdrawals
    • Net annual change
    • Year-end balance
  • Comparative Analysis:
    • Year-over-year growth
    • Transaction volume trends
    • Balance progression
