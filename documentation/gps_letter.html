GPS Letter Management System Documentation

Overview

The GPS Letter Management System is a comprehensive solution for generating, managing, and tracking GPS-related letters. It consists of three main components:

  • GPS Letter Generator - Interface for creating new letters
  • Letter Templates Management - System for managing letter templates
  • Letter Generation - Backend process for generating letters

Database Structure

Tables

1. letter_templates
Column Type Description
id INT Primary key, auto-increment
letter_code VARCHAR(50) Unique code for the template
letter_for VARCHAR(255) Purpose of the letter
location VARCHAR(255) Location information
subject VARCHAR(255) Letter subject
letter_content TEXT Template content
2. generated_letters
Column Type Description
id INT Primary key, auto-increment
template_id INT Foreign key to letter_templates
reference_no VARCHAR(50) Unique reference number
client_name VARCHAR(255) Client name
phone VARCHAR(50) Client phone number
address TEXT Client address
tin_number VARCHAR(50) Client TIN number
fs_number VARCHAR(50) FS number
status INT Letter status
created_at DATETIME Creation timestamp
3. letter_vehicles
Column Type Description
id INT Primary key, auto-increment
letter_id INT Foreign key to generated_letters
plate_number VARCHAR(50) Vehicle plate number
trailer_plate VARCHAR(50) Trailer plate number
chassis_number VARCHAR(50) Vehicle chassis number
motor_number VARCHAR(50) Vehicle motor number
imei_number VARCHAR(50) GPS device IMEI number
created_at DATETIME Creation timestamp

Letter Generator

Features

  • Template selection
  • Client information input
  • Multiple vehicle details entry
  • Letter preview
  • Letter generation

Form Sections

1. Template Selection
  • Dropdown for selecting letter template
  • Dynamic loading of templates
2. Client Information
  • Client Name (required)
  • Phone Number (with +251 prefix)
  • TIN Number (10 digits)
  • FS Number
  • Address
3. Vehicle Details
  • Plate Number (required)
  • Trailer Plate
  • Chassis Number (required)
  • Motor Number
  • IMEI Number (required)

Letter Templates

Management Features

  • Create new templates
  • View existing templates
  • Edit template details
  • Delete templates

Template Fields

  • Letter Code - Unique identifier
  • Letter For - Purpose description
  • Location - Geographic context
  • Subject - Letter subject
  • Content - Template body

Letter Generation

Process Flow

  1. Validate input data
  2. Generate reference number
  3. Save letter details to database
  4. Save vehicle information
  5. Generate HTML preview
  6. Enable printing functionality

Generated Letter Format

  • Company header with logo
  • Reference number and date
  • Client information
  • Letter subject and content
  • Vehicle details table
  • Signature section

Validation

Required Fields

  • Template selection
  • Client name
  • Vehicle plate number
  • Chassis number
  • IMEI number

Format Validation

  • Phone number: 9 digits after +251
  • TIN number: 10 digits
  • Reference number format: GPS/FS/[number]/[year]
