Suppliers Management System Documentation

Overview

The Suppliers Management System is a comprehensive solution for managing supplier information and relationships. It provides functionality for creating, viewing, updating, and deleting supplier records, with integrated purchase history tracking.

Database Structure

Tables

1. suppliers
Column Type Description
id INT Primary key, auto-increment
company_name VARCHAR(255) Company name
contact_person VARCHAR(255) Contact person name
phone VARCHAR(50) Contact phone number
email VARCHAR(255) Contact email address
address TEXT Company address
active INT Status (1=Active, 0=Inactive)

Features

  • Create, read, update, and delete suppliers
  • Contact information management
  • Purchase history tracking
  • Status management
  • Input validation
  • Integration with purchase system

Create Supplier

Process Flow

  1. Enter company name
  2. Add contact person details
  3. Enter contact information
  4. Add company address
  5. Set status
  6. Save supplier

View Suppliers

The system displays suppliers in a DataTable with the following information:

  • Company Name
  • Contact Person
  • Phone
  • Email
  • Status
  • Actions (Edit/Delete)

Update Supplier

Process Flow

  1. Load existing supplier details
  2. Modify company information
  3. Update contact details
  4. Update status if needed
  5. Save changes

Delete Supplier

Process Flow

  1. Display confirmation dialog
  2. Check for related purchases
  3. Soft delete (mark as inactive)
  4. Update status

Purchase History

Features

  • View all purchases by supplier
  • Track purchase amounts
  • View purchase dates
  • Track payment history

Validation

Required Fields

  • Company Name
  • Contact Person
  • Phone
  • Email

Business Rules

  • Company name must be unique
  • Email must be valid format
  • Phone must be valid format
  • Status must be valid

API Reference

Endpoints

Endpoint Method Description

/php_action/fetchSuppliers.php GET Get all suppliers
/php_action/fetchSelectedSupplier.php POST Get specific supplier
/php_action/updateSupplier.php POST Update supplier
