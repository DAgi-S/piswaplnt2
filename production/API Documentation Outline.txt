    Authentication Endpoints

        Login Endpoint (POST /api/v2/auth/login)
            Description: Authenticates users and returns an access token and refresh token.
            Request Body:

{
  "email": "user@example.com",
  "password": "yourpassword"
}

Response:

    {
      "access_token": "jwt_access_token",
      "refresh_token": "jwt_refresh_token"
    }

    Errors:
        401 Unauthorized: Invalid credentials.
        400 Bad Request: Missing or invalid parameters.

Token Refresh Endpoint (POST /api/v2/auth/refresh)

    Description: Issues a new access token using a valid refresh token.
    Request Body:

{
  "refresh_token": "jwt_refresh_token"
}

Response:

    {
      "access_token": "new_jwt_access_token"
    }

    Errors:
        400 Bad Request: Missing or invalid refresh token.
        401 Unauthorized: Invalid or expired refresh token.

Token Validation Endpoint (POST /api/v2/auth/validate)

    Description: Validates the access token to ensure it is active.
    Request Headers:
        Authorization: Bearer <access_token>
    Response:

        {
          "valid": true
        }

        Errors:
            401 Unauthorized: Invalid or expired token.
