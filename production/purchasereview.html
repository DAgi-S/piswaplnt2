1. Overview

The purchase module is a comprehensive system for managing purchase orders and raw materials inventory. It includes functionality for creating, editing, and managing purchase orders, supplier management, and inventory tracking.

2. Core Features

  • Purchase Order Creation and Management
  • Supplier Management with Quick Add Feature
  • Raw Material Inventory Tracking
  • VAT and Withholding Tax Calculations
  • Automatic Purchase Number Generation (Format: PO-YYYYMMDD-XXX)
  • Real-time Total Calculations
  • Payment Status Tracking
  • Stock Movement Recording

3. File Structure

  • purchase.php - Main interface and modals
  • custom/js/purchase.js - Client-side functionality
  • php_action/createPurchase.php - Purchase creation logic
  • php_action/editPurchase.php - Purchase editing functionality
  • php_action/removePurchase.php - Purchase removal handling
  • php_action/fetchPurchases.php - Purchase data retrieval
  • php_action/fetchSelectedPurchase.php - Individual purchase data fetching

4. Database Integration

The module interacts with several database tables:

  • purchases - Main purchase order information
  • purchase_items - Individual items in each purchase
  • suppliers - Supplier information
  • raw_materials - Inventory tracking
  • raw_material_movements - Stock movement history

4.1 Database Table Structures

4.1.1 purchases Table

CREATE TABLE purchases (
    id INT PRIMARY KEY AUTO_INCREMENT,
    purchase_number VARCHAR(50) UNIQUE,
    supplier_id INT,
    purchase_date DATE,
    sub_total DECIMAL(10,2),
    vat DECIMAL(5,2),
    grand_total DECIMAL(10,2),
    withholding_tax_enabled TINYINT(1),
    withholding_tax_amount DECIMAL(10,2),
    payment_status TINYINT(1) DEFAULT 0, -- 0:No Payment, 1:Full Payment, 2:Partial Payment
    paid_amount DECIMAL(10,2) DEFAULT 0,
    note TEXT,
    status TINYINT(1) DEFAULT 1,
    active TINYINT(1) DEFAULT 1,
    created_by INT,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP,
    FOREIGN KEY (supplier_id) REFERENCES suppliers(id),
    FOREIGN KEY (created_by) REFERENCES users(id)
)

4.1.2 purchase_items Table

CREATE TABLE purchase_items (
    id INT PRIMARY KEY AUTO_INCREMENT,
    purchase_id INT,
    raw_material_id INT,
    quantity DECIMAL(10,2),
    rate DECIMAL(10,2),
    total DECIMAL(10,2),
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (purchase_id) REFERENCES purchases(id),
    FOREIGN KEY (raw_material_id) REFERENCES raw_materials(id)
)

4.1.3 raw_materials Table

CREATE TABLE raw_materials (
    id INT PRIMARY KEY AUTO_INCREMENT,
    name VARCHAR(255),
    code VARCHAR(50) UNIQUE,
    category_id INT,
    unit VARCHAR(20),
    current_stock DECIMAL(10,2) DEFAULT 0,
    minimum_stock DECIMAL(10,2),
    cost_per_unit DECIMAL(10,2),
    description TEXT,
    status TINYINT(1) DEFAULT 1,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP,
    FOREIGN KEY (category_id) REFERENCES raw_material_categories(id)
)

4.1.4 raw_material_movements Table

CREATE TABLE raw_material_movements (
    id INT PRIMARY KEY AUTO_INCREMENT,
    material_id INT,
    movement_type ENUM('in', 'out'),
    quantity DECIMAL(10,2),
    reference_type VARCHAR(50), -- 'purchase', 'production', 'adjustment'
    reference_id INT,
    notes TEXT,
    created_by INT,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (material_id) REFERENCES raw_materials(id),
    FOREIGN KEY (created_by) REFERENCES users(id)
)
