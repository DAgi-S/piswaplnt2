PiStock Inventory Management System Documentation

1. System Overview

PiStock is a comprehensive inventory management system designed to handle various aspects of business operations including:

  • Inventory Management
  • Order Processing
  • Purchase Management
  • Quotation System
  • Financial Accounting
  • GPS Business Management
  • Digital Transaction Management
  • User Access Control
  • Reporting and Analytics

2. Core Subsystems

2.1 Inventory Management

Handles product management with features including:

  • Product CRUD operations
  • Stock tracking
  • Product categorization
  • Brand management
  • Stock alerts for minimum levels
  • Product image management
  • Stock movement history

2.2 Order Management

Comprehensive order processing system with:

  • Order creation and tracking
  • Multiple payment methods
  • Order status management
  • Order history
  • Invoice generation
  • Payment tracking

2.3 Purchase Management

Handles supplier interactions and purchases:

  • Supplier management
  • Purchase order creation
  • Purchase tracking
  • Purchase history
  • Supplier payment management
  • Purchase reports

2.4 Financial Management

Comprehensive financial tracking system:

  • Account management
  • Transaction categorization
  • Financial reporting
  • Audit trails
  • Digital transaction tracking
  • Category-based reporting

2.5 GPS Business Management

Specialized module for GPS-related business:

  • GPS business cycles
  • Profit distribution
  • Business reports
  • Letter generation
  • GPS payment tracking

3. Technical Architecture

3.1 Frontend Technologies

  • HTML5, CSS3, JavaScript
  • Bootstrap for responsive design
  • jQuery for DOM manipulation
  • DataTables for data presentation
  • Select2 for enhanced dropdowns
  • SweetAlert2 for notifications

3.2 Backend Technologies

  • PHP for server-side processing
  • MySQL database
  • RESTful API architecture
  • Session-based authentication
  • Role-based access control

3.3 Database Structure

Key database tables include:

Table Category Tables Purpose
Product Management products, categories, brands Store product information and classifications
Order Management orders, order_items, sales_orders Handle order processing and tracking
Purchase Management purchases, purchase_items, suppliers Manage purchase orders and supplier information
Financial Management accounts, transactions, categories Track financial transactions and categorization
User Management users, roles, permissions Handle user access and permissions

7. Development Guidelines

  • Follow MVC architecture patterns
  • Use prepared statements for database queries
  • Implement proper error handling
  • Maintain audit logs for critical operations
  • Follow coding standards and documentation practices
  • Regular testing and validation

8. Deployment Requirements

  • Web Server: Apache/Nginx
  • PHP Version: 7.4 or higher
  • MySQL Version: 5.7 or higher
  • Required PHP Extensions:
    • mysqli
    • pdo
    • gd
    • curl
    • json
  • Minimum Server Requirements:
    • 2GB RAM
    • 10GB Storage
    • Modern CPU with 2+ cores
